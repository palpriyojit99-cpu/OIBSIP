# BMI Calculator

## Objective
A Python command-line program that calculates a user's Body Mass Index (BMI) 
based on their weight and height, and classifies it into standard health categories.

## Features
- Takes weight (kg) and height (m) as input
- Calculates BMI using the formula: BMI = weight / (height²)
- Classifies result into: Underweight, Normal, Overweight, or Obese
- Validates input: rejects non-numeric values and negative numbers with clear error messages

## Tech Stack
- Python 3 (built-in functions only — no external libraries)
- Built and tested using Pydroid 3 on Android

## How to Run
1. Open `bmi_calculator.py` in any Python environment
2. Run the script
3. Enter your weight in kg and height in meters when prompted
4. View your BMI and category

## Example Output
Enter your weight in kg: 65
Enter your height in meters: 1.7
